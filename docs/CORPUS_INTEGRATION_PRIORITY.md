# Corpus Integration Priority

Public UI must never imply that a Nikāya contains only the small number of cards currently exposed by the web catalog.

Immediate data priority:
1. Materialize and publish complete Majjhima Nikāya corpus.
2. Continue Saṁyutta Nikāya completion.
3. Materialize Aṅguttara Nikāya corpus and connect it to the public catalog/search.
4. Build the Khuddaka Nikāya book-level corpus model and connect each available book progressively.
5. Only after verified source/right checks, extend the same pipeline to Vinaya and Abhidhamma.

Until a collection is fully integrated, public wording must say that the visible entries are the portion currently opened in the library, not the total size of the collection.
