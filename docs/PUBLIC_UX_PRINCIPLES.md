# Public UX Principles

Durable product rule for the Theravāda Pāli Canon Library.

1. Public-facing pages are for readers and practitioners, not operators. Avoid exposing implementation jargon such as canonical/index/pending/materialized/checkpoint/worker/state unless the user explicitly opens a project-progress or technical page.
2. The public voice should feel like a calm Buddhist library: clear, warm, respectful, easy to scan on mobile, and oriented toward reading, listening, reflection, and source verification.
3. Use short, accurately attributed canonical sayings to give rhythm and meaning to empty space and transitions. Prefer ancient Pāli Canon passages or fresh in-house translations from the Pāli, with exact references. Never invent a quote or attribute a modern paraphrase to the Buddha.
4. Search/filter labels should use reader language: “Đọc”, “Nghe”, “Có audio”, “Bộ kinh”, “Chủ đề”, “Tìm lời dạy…” rather than engineering terminology.
5. Five Nikāyas are a section inside the wider Theravāda Tipiṭaka library. Public navigation should make Sutta, Vinaya and Abhidhamma understandable without technical clutter.
6. Corpus coverage and catalog coverage must not be conflated. If a collection has thousands of indexed/full-text items but the UI catalog exposes only a few cards, the UI must clearly indicate the catalog is incomplete and the integration task is a priority; it must not imply the collection itself contains only those few texts.
7. Public counts should come from current corpus/media state, not hard-coded snapshots. Technical diagnostics belong on the progress/ops pages.
8. Current public language scope remains focused on vi, th, my, si, km, lo, en and zh unless the project scope document is intentionally revised.

Suggested canonical accents for Vietnamese UI (fresh translation from Pāli; keep references visible):
- “Các pháp do tâm dẫn đầu, tâm làm chủ, tâm tạo tác.” — Dhammapada 1 (Manopubbaṅgamā dhammā…)
- “Không làm mọi điều ác, thành tựu các điều lành, thanh lọc tâm mình.” — Dhammapada 183 (Sabbapāpassa akaraṇaṃ…)
- “Chính mình là nơi nương tựa của mình.” — Dhammapada 160 (Attā hi attano nātho…)

These principles should be applied to future homepage, navigation, search, collection pages, reader screens, legal/trust pages, and new Theravāda canon sections.
