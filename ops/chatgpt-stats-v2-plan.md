# Stats V2

Privacy-preserving analytics expansion for the public scripture library.

Planned dimensions: anonymous visitor/session, pages per visitor/session, landing/exit pages, engaged time, scroll depth, internal search terms, referrer domain, device/browser/OS, coarse Cloudflare geolocation, new/returning visitor, and human/likely-bot/unknown classification. Never persist IP, email, or names.

External Google search queries should come from Google Search Console rather than referrer URLs because search engines often suppress query terms.
