# 5 Đại Tạng Kinh Nikāya

Modern multilingual Next.js library for the Five Nikāya collections. Built for long-form reading, browser/device TTS, generated PDFs, optional matched-language MP3, source-aware content rights, RAG/Knowledge exports, and contextual YouTube embeds.

> **Bắt đầu ở `PROJECT_STATE.md`.** Đây là bộ nhớ dự án chuẩn dùng để tiếp tục công việc ở tab ChatGPT/Codex mới mà không dựng lại từ đầu. Coding agents cũng phải đọc `AGENTS.md`.

## UX
- Product-style library dashboard instead of a long marketing landing page.
- Responsive breakpoints for phone, tablet/DeX, desktop, and wide displays.
- Mobile bottom navigation plus global header menu/search.
- Reader controls for font size, dark mode, save position, and resume.
- Browser/device TTS reads the full text directly and does not depend on external MP3 hosting.
- Optional matched-language MP3 keeps speed controls from 0.75× to 2× plus ±15-second seek.
- PDFs are generated by the library from the current reader content using a branded template.
- Reader quick navigation includes Home, Library, previous/next, and jump-to-discourse.
- YouTube is hidden unless a discourse actually has a mapped contextual video.

## Vietnamese reference codes
TrB = Trường Bộ (DN), TB = Trung Bộ (MN), TƯB = Tương Ưng Bộ (SN), TCB = Tăng Chi Bộ (AN), TiB = Tiểu Bộ (KN). Vietnamese codes are primary in the Vietnamese UI; international codes are secondary references.

## Languages
16 UI locales: Vietnamese, English, Chinese, Hindi, Spanish, Arabic, French, Bengali, Portuguese, Russian, Indonesian, Urdu, German, Japanese, Korean, and Thai.

## Data / RAG
Canonical metadata lives in `data/catalog/*.json`. Run `npm run rag:export` for JSONL RAG/Knowledge exports with stable IDs and content hashes. See `data/README.md`.

## Content rights
Do not mirror or redistribute a translation/audio source unless its license or permission allows it. Source and rights metadata must remain attached to each discourse/chunk.

## Quality gate
Every push must pass RAG export validation, `next build`, and route smoke tests before deployment.
